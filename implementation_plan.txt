 1. EXPERIENCE AND NON-NEGOTIABLES
--------------------------------------------------------------------------------

The entire demo is one Unity scene: Assets/Scenes/PixBand_Demo.unity. It opens
on a menu in the forest. ENTER GAME starts walking, CONTROLS shows the VR and
PC bindings, and EXIT quits (or stops Play Mode in the Editor). There is no
scene load or teleport transition. R on PC, B/Y on Quest, and the in-world
reset flow return both rigs to the forest spawn in the same scene.

From the forest path, the player approaches a small haunted mansion shell. Its
front door stays open; from inside, the doorway frames the forest. Inside is
only a compact drum setup on a low riser. The drum kit is silent and its sticks
cannot be grabbed until the player is within about 3.4 m. The player grabs a
stick with VR grip or PC E and hits pads to play spatial one-shots.

The forest is dark, green, foggy and dense. Trees are merged into chunk meshes;
foliage and lights do not cast shadows. The mansion uses a thick, closed gable
roof and a separate interior ceiling to avoid holes and z-fighting.

 3. CONTROLS
--------------------------------------------------------------------------------

Quest 3 / 3S
  Left thumbstick       Move
  Right thumbstick      Snap turn
  Grip                  Grab / release a drum stick
  Trigger               Select world menu buttons
  B or Y                Reset to forest spawn

Laptop / desktop
  WASD                  Move
  Mouse                 Look (mouse click locks; Escape frees)
  E                     Grab next stick; with both held, drop both
  Left mouse click      Strike a pad while holding a stick
  R                     Reset to forest spawn
  Tab                   Toggle desktop rig / XR Device Simulator
  M                     Reopen the menu
  Enter                 Start from the menu; Esc closes Controls

--------------------------------------------------------------------------------
 4. UNITY SETUP AND BUILD
--------------------------------------------------------------------------------

Required packages already configured in the project:
  - XR Interaction Toolkit 2.5.4 + Input System 1.7.0
  - OpenXR 1.17.1 + XR Plug-in Management 4.4.0
  - TMP Essential Resources and the XRI Starter Assets / XR Device Simulator

Quest Android target:
  - IL2CPP, ARM64, minimum Android API 29
  - OpenXR Android loader, Meta Quest Support / Touch Plus / Touch Pro features
  - Vulkan + GLES3, Single Pass Instanced, Linear color
  - Application identifier: com.pixband.vr

In the Unity Editor:
  1. Open the project in Unity 2022.3.62f3.
  2. If scripts or packages changed outside the Editor, wait for compilation.
  3. Use PixBand > Rebuild Demo Scene when the generated scene needs refreshing.
     The builder also creates/updates the drum prefab and the one-scene build list.
  4. Use PixBand > Build Android APK. The output is Builds/pixBand.apk.
  5. Use PixBand > Build Linux Desktop for Builds/Linux/pixBand.x86_64.

Command-line Android build method:
  PixBand.EditorTools.PixBandBuild.BuildAndroidBatch

The previous baseline APK was built successfully as Builds/pixBand-test.apk.
Rebuild it after the final scene/script edits; do not treat that earlier APK as
the final one-scene demo build.

--------------------------------------------------------------------------------
 7. FROM-SCRATCH REBUILD NOTES
--------------------------------------------------------------------------------

PixBandSceneBuilder is deterministic for the generated scene and assets. It
opens the retained source kit scene additively, writes DrumKit.prefab, constructs
the forest/mansion/menu/rigs, saves PixBand_Demo.unity, and sets the build list
to that scene alone. It does not delete or rewrite the retained source scenes.
The forest tree meshes are combined into two renderers per spatial chunk; keep
trunk and foliage as separate single-material meshes to avoid foliage loss.

All generated content is built from Unity primitives, procedural meshes,
project-owned scripts, and the existing free drum samples. No network download
or paid asset is required to regenerate the scene.
